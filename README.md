# NftActuator

NftActuator is a smart, event-driven controller and optimizer for real-time digital asset processing and auto-scaling infrastructure.

The key benefits of using NftActuator include:

- NftActuator is a smart, event-driven
- controller and optimizer for real-time
- digital asset processing and auto-scaling

## Key Features

- NftActuator is a smart, event-driven

- digital asset processing and auto-scaling

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftActuator.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NftActuator is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
